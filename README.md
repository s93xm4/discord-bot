# Discord Echo Bot

這是一個 Discord 組團 bot：使用 slash command 開副本團、加入副本團、查看目前人數，並把資料記錄到線上 Postgres 資料庫。

## 需求

- Node.js 20 或更新版本
- Discord Developer Portal 建好的 bot token
- 線上 Postgres 資料庫連線字串

## Discord 設定

1. 到 Discord Developer Portal 建立 Application。
2. 在 `Bot` 頁面新增 bot，複製 token。
3. 到 `OAuth2 > URL Generator`：
   - Scopes 勾 `bot`、`applications.commands`
   - Bot Permissions 勾 `Send Messages`、`Read Message History`、`View Channels`
4. 用產生的網址把 bot 邀請進你的伺服器。

## 本機執行

```bash
npm install
Copy-Item .env.example .env
npm start
```

把 `.env` 裡面的 `DISCORD_TOKEN` 改成你的 Discord bot token，`DATABASE_URL` 改成你的線上資料庫連線字串。

## 免費線上 DB：Neon Postgres

Neon 的免費方案適合練習 Discord bot：

- 免費方案不需要信用卡。
- 每個 project 有 0.5 GB storage。
- 閒置 5 分鐘後會自動暫停 compute，下次查詢時再喚醒。
- 免費方案每個 project 每月有 100 CU-hours。

### 建立 Neon DB

1. 到 https://neon.com 註冊並登入。
2. 建立新的 Project。
3. 建立完成後，到 `Connection Details`。
4. 選擇 `Node.js` 或 `Postgres` 連線格式。
5. 複製 connection string，格式大概像這樣：

```text
postgresql://user:password@host/database?sslmode=verify-full
```

6. 貼到 `.env`：

```env
DISCORD_TOKEN=你的 Discord bot token
DATABASE_URL=你的 Neon connection string
```

## 指令

目前所有功能都使用 Discord slash command：`/開團`、`/加入團`、`/加入`、`/踢出`、`/管理團`、`/查團`、`/招募板`、`/解散團`、`/修改通知`、`/修改時間`。

### Slash Commands

```text
/開團 副本:243 人數:6 日期:2026/09/01 時間:22:00 地點:蒙德老家 預設人數:2 提醒分鐘:60 通知所有人:true 需要審核:true
/加入團 團號:20260901001 職業:VI
/加入 團號:20260901001 成員:@玩家 職業:VI
/踢出 團號:20260901001 成員:玩家名稱
/管理團 團號:20260901001 申請者:玩家名稱 動作:核准
/查團 團號:20260901001
/招募板
/解散團 團號:20260901001
/修改通知 團號:20260901001 動作:開啟 提醒分鐘:60 通知所有人:true
/修改通知 團號:20260901001 動作:停止
/修改時間 團號:20260901001 日期:2026/09/01 時間:22:30
```

### 開團

```text
/開團 副本:243 人數:6 日期:2026/09/01 時間:22:00 地點:蒙德老家 預設人數:2 提醒分鐘:60 通知所有人:true 需要審核:true
```

必填：

- 副本名稱
- 人數
- 日期
- 時間
- 地點

選填：

- `預設人數`：代表原本就有幾個人，只再找剩下的人。
- `提醒分鐘`：定時提醒還缺多少人。
- `通知所有人`：提醒時會加上 `@everyone`；沒選就只發普通訊息。
- `需要審核`：玩家使用 `/加入團` 後會先變成待審，團長需使用 `/管理團` 核准或拒絕。

開團完成後，bot 會發一則 `@everyone` 訊息通知有新團正在找人，並提示大家用 `/加入團` 加入。

### 加入或修改職業

```text
/加入團 團號:20260901001 職業:VI
```

同一個人不能重複加入同一團；再次加入會視為修改職業。
如果該團設定需要審核，使用 `/加入團` 後會先送出申請，bot 會提醒團長使用 `/管理團` 處理。

### 團長手動加入成員

```text
/加入 團號:20260901001 成員:@玩家 職業:VI
```

只有開團者可以使用。`成員` 使用 Discord 內建成員選擇器，團長可以直接從伺服器成員列表選人。

### 踢出團員

```text
/踢出 團號:20260901001 成員:玩家名稱
```

只有開團者可以使用。先填 `團號`，再到 `成員` 欄位選擇該團目前的正式成員或候補成員。

### 管理團

```text
/管理團 團號:20260901001 申請者:玩家名稱 動作:核准
/管理團 團號:20260901001 申請者:玩家名稱 動作:拒絕
```

只有開團者可以使用。先填 `團號`，再到 `申請者` 欄位選擇待審申請者。核准時如果正式名額已滿，會自動排入候補。

### 查團

```text
/查團 團號:20260901001
```

會列出副本、人數、缺額、正式成員職業、候補成員職業，以及待審數量。
也會列出開團者名稱。成員與候補只顯示使用者名稱，不會在查團時 `@` 他們。

### 招募板

```text
/招募板
```

會列出目前伺服器內正在招募、時間還沒到、且尚未滿人的副本團，並顯示團號、副本、團長、時間、地點、缺額與加入方式。

### 修改時間

```text
/修改時間 團號:20260901001 日期:2026/09/01 時間:22:30
```

只有開團者可以修改副本時間。修改成功後，bot 會 `@` 正式成員與候補成員通知新時間。

### 解散團

```text
/解散團 團號:20260901001
```

只有開團者可以解散自己的副本團。解散後會停止自動通知，也不會再到點提醒，bot 也會 `@` 正式成員與候補成員通知該團已解散。

### 修改通知

```text
/修改通知 團號:20260901001 動作:開啟 提醒分鐘:60 通知所有人:true
/修改通知 團號:20260901001 動作:停止
```

只有開團者可以修改該團的自動通知。開啟通知時如果該團原本沒有提醒間隔，需要填 `提醒分鐘`。

## 資料表

程式啟動時會自動建立 `raid_groups`、`raid_group_members`，並補上審核所需欄位。

## 注意

預設人數只會影響缺額計算，因為 bot 不知道那些人的 Discord 帳號，所以到副本時間時只能 `@` 實際加入過的成員。
